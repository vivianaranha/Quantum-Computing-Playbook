# Capstone Rubric

Score each section from 0 to 4.

## 1. Problem framing
- 0: No clear problem
- 1: Vague task
- 2: Defined task but weak motivation
- 3: Clear problem and quantum rationale
- 4: Clear problem, constraints, stakeholders, and falsifiable rationale

## 2. Classical baseline
- 0: None
- 1: Mentioned
- 2: Basic baseline
- 3: Appropriate baseline with metrics
- 4: Multiple strong baselines or justified best-known comparison

## 3. Quantum method
- 0: Unexplained circuit
- 1: Circuit copied without reasoning
- 2: Basic explanation
- 3: Correct end-to-end explanation
- 4: Correct explanation plus resource and noise considerations

## 4. Experiment design
- 0: No method
- 1: Single anecdotal run
- 2: Repeatable procedure
- 3: Metrics, repeated runs, and uncertainty
- 4: Controlled comparison with reproducible settings

## 5. Results
- 0: No results
- 1: Screenshots only
- 2: Basic numbers
- 3: Interpreted metrics
- 4: Quantitative comparison against baseline and expectations

## 6. Limitations
- 0: None
- 1: Generic caveat
- 2: Some constraints
- 3: Specific technical limitations
- 4: Honest limitations plus next experiment that would test them

## 7. Communication
- 0: Not understandable
- 1: Fragmented
- 2: Adequate
- 3: Clear and structured
- 4: Clear to both technical and business audiences

### Suggested target
Aim for **22/28 or better** before considering the capstone portfolio-ready.
